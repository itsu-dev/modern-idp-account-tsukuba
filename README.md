# modern-idp-account-tsukuba
筑波大学の統一認証のログイン画面を少しだけおしゃれにします．

<img width="1282" alt="image" src="https://github.com/user-attachments/assets/ca0b4cb6-e24d-481b-b4d4-eee54d62975a" />

## 開発
### 最初の一回のみ
#### パッケージのインストール
```sh
pnpm i
```

#### ビルド
```sh
pnpm run dev
```

#### 拡張機能の適用
[Development basics | CRXJS Vite Plugin](https://crxjs.dev/vite-plugin/getting-started/vanilla-js/dev-basics)

### 開発時に常に実行
crx.js を利用しているため，HMR を有効化した開発が可能です．

```sh
pnpm run dev
```
